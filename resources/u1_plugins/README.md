# Optional U1 integrations

The generated wheels are included here in application distributions. The native plugin
manager stages missing bundled packages into this application's own plugin directory,
where they appear disabled. Existing packages are not replaced. Enable a package
explicitly, review requested dependencies/permissions, then Run its script capability.
No printing, macros or hardware actions run automatically. See docs/plugins/integrations.md.

Developer build: python tools/u1/build_plugins.py.
