# Original Snapmaker project regression fixtures

These files are unchanged outputs of the official Snapmaker Orca v2.4.1 CLI,
generated from this project's synthetic cube fixtures and exported U1 presets.
See SOURCE.json for hashes, the exact source tag and the release verification
record. The single-tool project has one filament; the corrected four-tool
project has four distinct filament colors and four objects. Both retain the
original automatic support expansion `-1` and stock machine macros.

No installed user configuration, credentials or physical printer was used.
The files are test inputs, not calibrated or approved print jobs. Tests may
load/save/slice them offline; never submit their embedded G-code to hardware
automatically. Snapmaker preset/code attribution remains under the repository's
inherited AGPL notices. These fixtures do not establish complete preservation
of currently unsupported Snapmaker configuration keys.
